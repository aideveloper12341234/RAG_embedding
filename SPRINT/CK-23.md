# CK-23 Say "Details not available" when we have no document, and give the escalation guidance

## Description

As a dispatcher, I want to be told plainly when there is no document for this alarm and what to do instead, so that I am not left with nothing on the unusual ones.

**What this covers:** Noticing there is no relevant document · the agreed message · the standard escalation guidance · recording the gap

**Work beneath this story** (indicative activities — the team writes its own tasks):

- **Dev:** Build the detection, the response and the gap record.
- **Business:** Confirm the escalation guidance wording and who receives the gap report.

**Note:** Carries part of the contracted Standardised Response Messaging deliverable, and needs no AI. The gap report gives Constellation a list of the alarms their documentation does not cover.

User story · Standardised response messaging · parent MON-E6 · internal plan Sprint 5 · client plan Sprint 6

## Acceptance Criteria

- When search finds nothing relevant, the response says "Details not available".
- It is followed by the standard escalation guidance agreed with Constellation.
- It does not read as a system error.
- Every such case is recorded against the alarm, so operations can see which alarms have no document.
- It is tested against the no-document alarms collected in CK-07.
